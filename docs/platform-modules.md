# Platform modules

A subset screen calls a platform API by name. The call is a static method, the first argument is the `IPlatform` parameter, and the lowerer emits `ActModule`. The Android host dispatches that name in `PlatformModules.Dispatch` with a switch. There is no reflection and no `Assembly.Load` on this path, so the same call is valid in the NativeAOT listener.

```csharp
Haptics.Confirm(host);
Share.Text(host, state.Email);
Clipboard.Copy(host, "form", state.Email);
```

| module | method | arguments after the platform | Android |
| --- | --- | --- | --- |
| `Haptics` | `Confirm` | none | `VibrationEffect` one-shot, or `haptic-unavailable` when the device has no vibrator |
| `Share` | `Text` | one string | `ACTION_SEND` text/plain. An empty string logs `share-skipped` and does not open the sheet |
| `Clipboard` | `Copy` | a label literal, then one string | `ClipboardManager`, then a read-back. The log is `clipboard-ok` |
| `Storage` | `Set` | a key literal, then one string | `SharedPreferences` `nativepoc-settings`, committed before the call returns. The log is `storage-set` |
| `Storage` | `Get` | a key literal | the same store. The result is a string, empty when the key is missing. The log is `storage-load` |
| `Theme` | `Mode` | `dark`, `light`, `system`, or a bool property | writes the same store under `theme` and repaints. A bool property is `dark` when true. An empty store is `ThemeMode.System`. `system` follows `uiMode`, including a change while the activity is up |
| `Animate` | `Play` | a key literal | replays the `Motion` last mounted on the view with that key. A missing key logs `motion miss` |
| `Animated` | `Timing`, `Spring` | a key literal, then from, to, and a duration in milliseconds | scales that view from `from` to `to` (percent). `Timing` is an ease-out. `Spring` settles at the end after a small overshoot. The duration is the basis times the smaller of `animator_duration_scale` and `transition_animation_scale`. Either scale at 0, or a basis of 0, applies `to` and does not post a frame. The log is `animated play` and, when a frame clock ran, `animated end`. A missing key logs `animated miss`. Nothing is scheduled until a screen calls it |
| `Http` | `GetJson` | one URL string | The default backend is `java.net.HttpURLConnection` through `PlatformHttp` on the JNI registry, off the UI thread. The body comes back as a string. A failure is `http-error:` plus a reason (`timeout`, `cancelled`, a status code, or an exception name). Connect and read time out at 8 seconds. The log is `http-get chars=` and `client=jni`, plus `jni-bind class=java/net/HttpURLConnection`. `Pop` cancels only that screen and `disconnect`s its sockets. `NativePocHttpManaged=true` uses one `HttpClient` on `SocketsHttpHandler` instead, and that log is `client=1`. An app that does not set `NativePocHttp` compiles neither backend |
| `Http` | `PostJson` | a URL string, then a JSON string | the same backend, POST, `application/json` |
| `Timer` | `After` | a millisecond int from 0 to 10000 | completes after that delay. The result is `ok` |
| `Location` | `Read` | none | runtime permission, then one GPS fix. The result is a string `Location.Parse` turns into `LocationFix`. `granted <lat> <lon> <accuracy>`, `denied`, or `permanently-denied`. Compiles only when `NativePocLocation` is true |
| `Nav` | `Push` | a screen id literal | pushes that screen. The log is `nav-focus heading=` when the new tree has a heading. `NavFocus.cs` is compiled only when `NativePocNav` is true |
| `Nav` | `Pop` | none | pops the stack. Android back calls the same pop. The log is `nav-back invoked` and then `nav-focus` on the screen that returns |
| `Transition` | push and pop | none | `NavTransition.cs` runs an Android `Slide` on the nav stage. It is compiled only when `NativePocTransition` is true. The duration is `MotionScale.DurationMs`. `animator_duration_scale` or `transition_animation_scale` at 0, which is what Remove animations sets, skips the transition. An edge drag tracks the current screen with the finger and reveals the screen under it. A short release settles, and a completed drag pops. The back button and the system back still pop, including with TalkBack. The commit threshold and the durations are `MotionContract` in Core. The logs are `nav-transition instant=` and `nav-swipe`. The authored UIKit host maps the swipe to `UINavigationController` interactive pop and the animation to `UIView` and `CADisplayLink`. `net10.0-ios` was not compiled. |
| `Persist` | `Get` | a key literal | async read of one string from the app's private `nativepoc-persist` directory. Missing is empty. The log is `persist-get`. The file copy is compiled only when `NativePocPersist` is true |
| `Persist` | `Put` | a key literal, then one string | async write of that string. The call returns `ok`. The log is `persist-put` |
| `Persist` | `GetRecord` | a key literal | the same file, decoded as a `PersistRecord` (`Id`, `Title`, `Note`) by `PersistCodec`. There is no reflection serializer. The log is `persist-record-load` |
| `Persist` | `PutRecord` | a key literal, then id, title, and note strings | writes that record and returns the codec text. The log is `persist-record` |
| `FeedModule` | `Apply` | the screen state, then a JSON string | a source-generated `System.Text.Json` context (`JsonSourceGenerationMode.Serialization`) reads `{ "items": [{ "id", "title" }] }` through `FeedDocumentConverter`. There is no reflection attribute factory. `http-error:` and an empty string clear the list. The log is `json-source items=` |
| `FeedModule` | `Generate` | the screen state | when `Generated` is empty, writes 1,000 rows. The id is `0000` through `0999` and the title is `Row ` plus that id. A list that already has rows is left as it is. The lowered program does the same write with `OpSeedList` and does not call the C# method |
| `Image` | the `Image` element | a source, a description, or `Decorative` | `ImageModule.cs` decodes with `BitmapFactory` `InSampleSize` fitted to the view, keeps a 32-entry memory LRU, shows a gray placeholder and a red error state, and sets the content description. It is compiled only when `NativePocImage` is true. The log is `image-sample in=`, `image-bitmap decoded=`, `image-bitmap drawn=`, `image-bitmap baked=`, `image-placed`, `image-placeholder`, and `image-cache hit source=` when a later bind reuses the bitmap. A remote source fetched with `NativePocHttp` uses that same HTTP backend. The default log is `image-http client=jni`. The cache key is the source plus a 64px bucket of the layout slot, not the measured width. A recycled row often has no width yet, and keying on that width missed. A source with a corner radius is scaled to the view and the radius is baked into one ARGB bitmap, which the view then draws with `drawBitmap`. That view does not clip to its outline and does not take a per-tile elevation. The Northroom shelf files are 512 by 512 JPEGs written by `tools/glaze/GlazeWrite.cs` into the intermediate output during the resource pass and are not stored in the repository. The pixels are a radial glaze, a highlight, and two soft runs that taper. A source that starts with `gen:` is a 48 px swatch drawn once and reused by later holders. The logs for that path are `image-gen` and `image-bitmap reuse`. A corner-radius bake runs on a worker. The UI thread presents one finished bitmap per frame and skips `SetImageBitmap` when the view already holds that bitmap. `cnative inspect` code `image-a11y` requires a description or `Decorative = true` |
| `Jni` | a `[JniType]` partial class | `[JniMethod]` name and JNI signature | `JniBindingGenerator` emits `JNIEnv` calls. The sample is `samples/bind`, compiled only when `NativePocJni` is true. The log is `jni-bind class=` |

`Theme.Mode` stores `dark`, `light`, or `system`. The default, when nothing is stored, is `ThemeMode.System`. `Theme.Mode(platform, ThemeMode.Dark)` sends `dark`. The bool overload still sends `true` or `false`, which persist as dark or light. A stored `light` or `dark` overrides the device. `system` reads `uiMode` on launch and again when `cmd uimode night` changes it. The activity lists `uiMode` in `configChanges`, so that change calls `OnConfigurationChanged`, restyles the mounted tree, and keeps the screen state and the process. Text is set in `sp`, and buttons wrap, so a font scale of 2 grows the line instead of clipping it. `cnative inspect` flags `fixed-height` when a vertical text container uses `Grow`, which is a fixed slot, or when the measured height does not grow at font scale 2. A horizontal `Grow` is a width weight and is not that slot. It flags `overflow` when a child extends outside its parent and is clipped, `system-bar` when a child sits under the status bar, and `button-label` when a button is taller than 56 dp. The host centres a button label and keeps that height between 48 and 56 dp before the font scale. The host applies system-bar insets on every screen and paints the status bar and the navigation bar with the page color when night changes, without recreating the activity. With `NativePocStartupMarks`, the first frame also logs `startup took phase=theme-resolve`, `gradient-create`, `shadow-create`, `stat-measure`, and `traversal`. `theme-resolve` is `Load` plus `ApplyWindow`. `gradient-create` and `shadow-create` are the time spent building those `GradientDrawable`s. `stat-measure` is the first measure of the home stats row. `traversal` is that scroll's first measure through its first layout. `scroll-measure`, `scroll-layout`, and `scroll-draw` are the durations inside those three passes. `scroll-measure-again` is a second measure of that scroll after the window relayout and before layout. `page`, `hero`, and `stat` repeat them for those subtrees. `pieces-measure`, `kept-measure`, and `kiln-measure` are the three stat cards, and `shelf-measure` and `room-measure` are the home buttons. The page column is marked when its key is `page`. `grid-measure` is the first measure of shelf `row-0`. The home cold start does not mount the shelf, so that mark is absent there. A parent whose children are all keyed can replace a parent whose children are all unkeyed, which is how the unkeyed warm column accepts `Screen.cs`. A parent that mixes the two is `subset.mixed-keys` and the overlay shows `file:line`.

Before the chrome callback, a view with `Background` or `Wash` paints a rectangular `ColorDrawable` and no outline. The color is the midpoint of the gradient when every text on that surface meets contrast, and otherwise the stop that does. The corner radius, the gradient, the elevation, and the stroke are applied on the callback two frames after the launch idle handler. `cnative inspect` code `contrast` checks each text against that first-frame color, and `tools/check.sh` fails the screen when the text does not meet it. SwiftShader magnifies the cost of a clip outline and of an elevation shadow. A host-GPU or device run of this frame is still pending.

`HeadlessLayout.MeasureBelowBars` shifts a tree down by 24 dp, the same inset `cnative inspect` uses. `Every_Northroom_screen_runs_on_the_headless_host` renders home, the shelf, the piece, and the room on `HeadlessHost`, checks that shift at font scale 2, the shared top-left back arrow, and the Keep button. That test does not compile the UIKit host. The canonical cold-start floor for Northroom is the widget floor in [getting-started.md](getting-started.md). It is an empty column in the same Release publish, not the Java list floor.

`ScreenNav.Show` replaces the program for an id and does not push. A cold launch whose root is that one screen has depth 1. `Push` is what stacks the next screen. `samples/notes` is the list, detail, and edit sample. It compiles only when `NativePocPersist` and `NativePocNav` are both true. `dotnet new cnative-app --nav` and `--persist` write those two properties. The host package adds `NavFocus.cs` and `PersistStore.cs` from `SelectHostModules`, after the app project has set the properties. The p44 default left both false, and that listener `.so` had neither `nav-focus` nor `persist-put`. This template defaults `NativePocNav` to true and leaves `NativePocPersist` false. A catalog `Show` keeps the stack the user built, including across a hot reload.

`Persist.Put(platform, key, PersistRows.Encode(state.Tasks, item => new[] { item.Id, item.Title }))` stores the whole list. The lambda is the field list. The reload VM writes the wire cells in that order. `PersistRows.Fill` reads it back after `Persist.Get`. `Persist.PutFields(platform, key, id, title)` stores one record of any width through `Persist.Put` and `PersistRows.EncodeFields`. `Persist.PutRecord` is still id, title, and note. `Http.GetJson`, `Http.PostJson`, `Storage.Get`, `Timer.After`, `Location.Read`, `Persist.Get`, `Persist.Put`, `Persist.GetRecord`, and `Persist.PutRecord` return `Task<string>`. A handler assigns them with `await`. The lowerer emits `ActAwait`. A task that is already finished writes the string and continues. A task that is still running suspends the action: the continuation is stored and resumed on the UI thread, and the step counter starts again for that segment. `Pop` cancels only the screen that left and requests a render of the screen underneath. A second screen's request stays live. The log is one `http-cancel module=` line.

The feed reader deserializes with a source-generated `System.Text.Json` context (`JsonSourceGenerationMode.Serialization`). The context constructs `FeedDocumentConverter` and does not emit a reflection attribute factory. `FeedModule.Apply` reads camelCase `items`, `id`, and `title` through that converter. When `NativePocHttp` is set, `System.Text.Json.JsonSerializer.IsReflectionEnabledByDefault` is false. The default transport is `PlatformHttp`: `[JniType("java/net/HttpURLConnection")]`, registered as `PlatformHttp.Exchange` and `PlatformHttp.Read`, called through `JniRegistry` from a worker thread. `disconnect` aborts that screen's sockets. The ASCII `System.Net.SocketsHttpHandler.Http3Support` in a JNI `.so` is the NativeAOT runtime feature-switch name table, beside `System.Net.Http.UseNativeHttpHandler` and `System.Reflection.Metadata.MetadataUpdater.IsSupported`. The JNI publish does not emit a `RuntimeHostConfigurationOption` for it. That option is compiled only when `NativePocHttpManaged` is true. `NativePocVisit` defaults to false. Setting it true compiles `samples/visit` and turns on HTTP, location, nav, and persist. `tools/check.sh` does not set it, so the default showcase does not include Visit. `NativePocHttpManaged=true` compiles `SocketsHttpHandler` instead and sets `System.Net.Http.UseSocketsHttpHandler` true, `System.Net.SocketsHttpHandler.Http3Support` false with `Trim=true`, and `System.Resources.UseSystemResourceKeys` true. An app that does not set `NativePocHttp` does not compile `HttpTransport`, `PlatformHttp`, or `samples/feed`. iOS would map that same `Http.GetJson` call to `NSURLSession`. `net10.0-ios` was not compiled. The listener used to publish with Debug's `AndroidLinkMode=None`, and that trim kept `System.Text.Json`. The listener property group now sets `AndroidLinkMode` to `SdkOnly`, `TrimMode` to `full`, and turns serialization discovery off. The bytes are in [devx/evidence/list-input.txt](devx/evidence/list-input.txt). `Http` and `samples/feed` compile only when `NativePocHttp` is true. A Release of the counter app does not pass that flag, so it does not reference `System.Net.Http`, `SocketsHttpHandler`, or the feed screen. The listener publish passes `-p:NativePocHttp=true` and `-p:NativePocRecycler=true`. The showcase Release sets `NativePocRecycler`. `tools/check.sh` passes `-p:NativePocHttp=true` so the Feed screen is in that package. A showcase publish that omits the flag does not. `NativePocRecycler` compiles `Java/nativepoc/KeyedList.java` into the APK. A `ListView` whose `Style.Across` is 2 or more uses `GridLayoutManager`, `setHasFixedSize`, an initial prefetch of 4, and a cache of three rows times the column count. The Northroom shelf is that grid. One column stays a `LinearLayoutManager`. The dex uses RecyclerView 1.2.1, core 1.3.2, and customview 1.0.0, fetched by `tools/bench/fetch-androidx.sh` into a gitignored cache and checked against `tools/bench/list-floor/deps.sha256`. Those versions do not reference Kotlin. The managed binding is not a compile reference. Every Release sets `AndroidLinkTool` to `r8`. `proguard-jni.cfg` keeps `StartupProbe`, `StartupApp`, and `net.dot.jni.nativeaot.NativeAotRuntimeProvider`. `proguard-list.cfg` keeps `nativepoc.KeyedList` and the native methods the host registers. The widget floor sets `NativePocRecycler` and `NativePocImage` false, and a build without the recycler flag drops the RecyclerView, core, and customview libraries before import. The reflective keep of every `LayoutManager` is removed, so `StaggeredGridLayoutManager` is not in the dex. On this run the showcase `classes.dex` stayed 309,468 bytes uncompressed and 135,242 compressed, and the widget floor dex went from 60,404 / 21,565 to 59,572 / 21,223. The floor dex has no `androidx.recyclerview`. The shrunk dex size is in [devx/evidence/scroll-floor.txt](devx/evidence/scroll-floor.txt). A Release of the counter passes neither flag. A URL or bitmap decode that downsamples to the view, with the placeholder and the error state, is `ImageModule` and compiles only when `NativePocImage` is true. The older full-size decode stays on `NativePocHttp` when that flag is on and `NativePocImage` is off. `KeyedList` publishes `CollectionInfo` with one row per line of the span and `CollectionItemInfo` in row-major order. The cell content description keeps the title and appends `n of count`. The log is `a11y-cell pos= of= label=`. `cnative inspect` codes `grid-order` and `grid-label` check that order and that the label contains the title when `Style.Across` is at least 2. `NativePocStress` defaults to false. Setting it true compiles `samples/showcase/StressScreen.cs`, turns `NativePocShowcase` on, and sets the application id to `com.scratch.nativepoc.stress`, so the 1,000-row bench is a separate package.

On this tree the clean JNI showcase, the `tools/check.sh` publish, is 3,813,690 bytes on android-x64 and 3,625,277 on android-arm64. The clean `NativePocHttpManaged=true` publish, not installed, is 5,370,170 and 5,103,933. On emulator-5554, SwiftShader, the JNI x64 feed logged `http-get chars=1154 client=jni`, `json-source items=30`, and `image-http client=jni bytes=299` with `image-sample in=128x128`. The screen showed Harbor glaze. Those byte counts and the cold-start series are in the progress79 paragraph of the README.

Adding a module is a row in that switch and a matching arm in `SubsetLowerer.ModuleCall`. An awaitable method is an arm in `AwaitArgs` instead. The screen does not look up a type at runtime.

`cnative agent submit <id>` runs a field's `OnSubmit`, which is where a form calls these modules. `cnative agent logs` shows `haptic-ok`, `haptic-unavailable`, `share-text`, `share-skipped`, `clipboard-ok`, `storage-set`, `storage-load`, `theme mode=`, `http-get`, `http-post`, `http-error`, and `http-cancel`.
