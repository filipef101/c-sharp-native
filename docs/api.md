# Public API

The screen contract is the types marked `stable`. A screen calls those static methods with its `IPlatform` and builds a tree from the element records. `experimental` is implemented and tested, and its shape can still change. `internal-ought-to-be` is public because a host, a generator, or a test already binds to it. It is not a contract. A new public type or member fails `PublicApiTests` until this file and `tests/NativePoc.Core.Tests/PublicApi.baseline.txt` are updated together.

`MainActivity`, `PackingActivity`, `RecreateReceiver`, and `FeedModule` are Android host types. `CompiledScreenGenerator` and `ReloadDispatchGenerator` are source generators. Those six are `internal-ought-to-be`. Their members are not listed. The test reads the source and fails if another public type appears in `src/NativePoc.Android` or `src/NativePoc.ReloadGen`.
