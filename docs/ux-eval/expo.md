# Expo first-run, documented vs tested

Fetched `2026-11-08` from Expo's public docs. **Not run on this machine.** Label every row below before quoting it. `docs/devx/comparison.md` on this commit also says "Not run here" for Expo, and that sentence is still accurate.

| Step | Expo, documented | This repo, tested in this session |
| --- | --- | --- |
| Create the app | **Documented.** `npx create-expo-app@latest --template default@sdk-58` ([Create a project](https://docs.expo.dev/get-started/create-a-project/)). | **Tested.** The app is the repo. There is no create command. |
| Environment | **Documented.** Node LTS; Android Studio or an SDK; `ANDROID_HOME`; `adb` on `PATH`; an emulator from Device Manager ([Set up your environment](https://docs.expo.dev/get-started/set-up-your-environment/)). | **Tested** for the SDK and the emulator, with a gap: the README lists SDK 36 and an x86_64 image and does not say how to create or boot the AVD. See [kvm.md](kvm.md) and finding F8. |
| First native install | **Documented.** `npx expo run:android` compiles, installs, and starts Metro. Later JS edits use `npx expo start` and press `a` ([Create a debug build locally](https://docs.expo.dev/guides/local-app-development/)). | **Tested.** `tools/devx/cnative run android` is the single command. It does not boot an emulator. First launch on empty app data stays up. The stock `Screen.cs` then fails `CS0246` until a using is added (F2). |
| Open the app | **Documented.** `npx expo start`, then `a` for an already running emulator, or a QR code for a device ([Start developing](https://docs.expo.dev/get-started/start-developing/)). | **Tested.** Launch is part of `cnative` and of `dotnet build -t:Run`. The activity string is `com.scratch.nativepoc/crc64ee53024f7ed0aa60.MainActivity`. |
| First edit | **Documented.** Change `src/app/index.tsx` (`Welcome to Expo` to `Hello World!`). Fast Refresh applies component edits on save ([Start developing](https://docs.expo.dev/get-started/start-developing/), [Fast Refresh](https://reactnative.dev/docs/fast-refresh)). | **Tested.** Nothing watches until `cnative` is running. A save of `src/NativePoc.Screen/Screen.cs` then printed `reloaded in 2682.9 ms (apply 47.3 ms)` and the UI changed from `Counter 1` to `Expo 1` with the typed name kept. Host mode `a` from the README is a 20-sample benchmark that restarts the app (F4). |
| Syntax error | **Documented.** A syntax error shows a red box. Fixing the file clears it without a manual reload ([Fast Refresh](https://reactnative.dev/docs/fast-refresh), [Errors and warnings](https://docs.expo.dev/debugging/errors-and-warnings/)). | **Tested.** `TitlePrefix = ;` printed `src/NativePoc.Screen/Screen.cs:7:36: error CS1525: Invalid expression term ';'`. The device stayed on the last good frame ([screenshots/b-compile-error.png](screenshots/b-compile-error.png)). Fixing the file printed `reloaded in 2517.0 ms (apply 21.0 ms)` and showed `Fixed 1`. |
| Edit that needs a native rebuild | **Documented.** A native module or a native project change needs `npx expo run:android` again. Fast Refresh falls back to a full reload for some non-component edits ([local app development](https://docs.expo.dev/guides/local-app-development/), [Fast Refresh](https://reactnative.dev/docs/fast-refresh)). | **Tested.** Adding a property on `AppState` printed `rude edit -> restart required` and `Restart the app? [y/N]`. `n` printed nothing else (F6). `y` rebuilt and launched pid `9323`. The name `Rio` was gone; the screen showed `Fixed 0` and `Enter a name`. |
| Second launch | **Documented.** `npx expo start` reuses the installed app. | **Tested.** A second `cnative run android` while a token file was left behind read the old token, printed `reload failed` / `EndOfStreamException`, and exited `1` (F1, F3). |

The timing cell is one-sided. Expo's docs say most Fast Refresh edits show up within a second or two. They do not publish a millisecond for this machine, and this session did not run Metro. The numbers `2682.9`, `47.3`, `2517.0`, and `21.0` are from `cnative` on this emulator only.
