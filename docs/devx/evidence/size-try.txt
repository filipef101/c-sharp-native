## Show

`Show` of an id that is not on the stack appends it. `Show` of the current top leaves the stack and replaces the program. `Show` of an id already further down moves that frame to the top and does not add a second copy. Frames that were above it stay underneath. That is the same stack effect as `Push` of an existing id. It is not React Navigation's `navigate`, which pops back and drops the screens above. `A_show_of_a_screen_already_on_the_stack_moves_that_frame_to_the_top` is the test. Tested. The pid 16153 tree in the notes walkthrough is the previous rule.

## try / catch / finally

An exception thrown in the interpreter unwinds to the nearest interpreted handler. `catch (Exception)` and `catch (ArithmeticException)` match `DivideByZeroException` by walking base types. `catch (FormatException)` does not. `finally` runs on the way out. An exception thrown in `finally` replaces the pending one. `try { return n; } finally { n = 9; }` returns the value from before `finally`. A catch variable the block reads, a `when` filter, and `return` inside `finally` are refused. An exception no handler takes stops the action with that exception's message. `ActionParityTests.Try_catch_finally_matches_compiled_csharp` and `MethodBodyTests.Try_catch_finally_matches_compiled_csharp` compare those results with compiled C#. `A_try_around_await_catches_a_throw_inside_if` awaits, then throws inside `if (state.Json.StartsWith(...))`, and the catch sets the phase. Tested.

`ReloadAotPublishTests` is the one fact that publishes a linux-x64 NativeAOT binary. It was left out of the previous Android run because that publish overlaps ILC. Run on its own it passed. Nothing in it failed. Tested.
