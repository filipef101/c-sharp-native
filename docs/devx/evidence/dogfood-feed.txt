# Feed, built through the listener

Emulator-run on boot `56815464-4bc4-4f4c-a503-944cb91ab31f`. The command was `tools/devx/cnative run android --listener --restart-on-rude --device emulator-5554 --root feed`. Nothing was published.

The screen is `samples/feed/FeedScreen.cs`. Refresh and a pull on the scroll call the same `Load` handler. That handler sets loading, awaits `Timer.After` then `Http.GetJson` of `http://10.0.2.2:8094/feed`, and on `http-error:` reads `Storage` key `feed-json`. A hit shows `offline` and the cached rows. A miss shows `error` and an empty list. Post calls `Http.PostJson`.

The server was `/tmp/feed-server.py` on `0.0.0.0:8094`. It is not in the repo. GET `/feed` waits 2 seconds and returns `{"items":[{"id":"a","title":"Ada"},{"id":"b","title":"Bea"}]}`. POST echoes the body. The emulator reaches the VM at `10.0.2.2`.

## Launch

pid 18899. `IsDynamicCodeSupported=False`. The shows were note, then notes, then feed, because `--root feed` shows that screen last. Reply `idle`. The tree was `idle`, Refresh, Post, Back. Without `--root`, `Show` does not move a screen that is already on the stack, so the alphabetical last screen (`notes`) would have stayed on top.
