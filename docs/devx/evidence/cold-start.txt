# Release cold start, this binary

Emulator-run. x86_64 API 34 emulator, boot `56815464-4bc4-4f4c-a503-944cb91ab31f`. `tools/bench/mac-bench.sh --n 20 --device emulator-5554`. One discarded warmup per series, then 20 rounds. Each round is counter, then the empty Java floor, then packing1000. Every sample is `am start -W -S` and LaunchState COLD. p50 and p90 are Hyndman-Fan type 7. The host has 4 cores. Load is the 1-minute average from `uptime` at the start of each round. No floor sample was above 1.5× its median, so the script printed no contended round. Both passes stay in the record.

x64 Release APK sha256 `066e572bcdee253bd561f10c012fbd28ae94b6c9fe12850fc63b6bada2da3eec` (2,814,765 bytes). `.so` sha256 `48d2cc9b8a5bf9e956a66d1a71dc3db9feead0bf3255536f0ef15eeabdd7db25` (6,507,536 bytes), same bytes inside the APK. `classes.dex` contains `NativeAotRuntimeProvider`. Floor APK sha256 `6dae9d0c01f3bb8879c40881a95c7c5e3704699852d01413a97a232f1560b469` (12,649 bytes). Not published. Mac numbers for this binary are not measured in this workspace.

Every counter log and every packing log in the second pass printed `IsDynamicCodeSupported=False`. The counter's first frame title is `Counter 0`. The notes screens are not in this APK.

`startup direction` is logged after `startup mark=first-present` and before `Displayed`. On the second pass the probe measure is usually about 1 ms. It is not the draw gap below.
