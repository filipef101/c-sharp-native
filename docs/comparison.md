# Comparison

This page only records facts that this tree or an official document states. It is not a benchmark. The timing log for `cnative` itself is [devx/comparison.md](devx/comparison.md). An older Mac `pixel_8` table that includes a MAUI empty baseline is in the README. That table was not remeasured for this page.

| | How a control becomes a platform widget | Where that is written |
| --- | --- | --- |
| This tree | A C# function returns an `Element`. `SubsetLowerer` writes an NPC1 record. `RecordProgram` evaluates it. `AndroidHost` constructs `android.widget` views. `RowWindow` is 20 recycled slots, not AndroidX `RecyclerView`. Release sets `PublishAot`. | [architecture.md](architecture.md), [`NativePoc.Android.csproj`](../src/NativePoc.Android/NativePoc.Android.csproj) |
| .NET MAUI | Handlers map virtual views to native views. The Button handler maps to a `UIButton` on iOS and a `MaterialButton` on Android. Mappers are dictionaries of actions. | [.NET MAUI handlers](https://learn.microsoft.com/en-us/dotnet/maui/user-interface/handlers/?view=net-maui-10.0) |
| Avalonia | Avalonia draws with its own renderer so the same UI description targets Windows, macOS, desktop Linux, iOS, Android, and WebAssembly. Native AOT is a documented publish mode (`PublishAot`, compiled bindings, no runtime XAML load). A `NativeControlHost` can embed a platform control. On macOS, Avalonia does not use the `net10.0-macos` workload. It ships its own native backend. | [Welcome](https://docs.avaloniaui.net/docs/welcome), [Native AOT](https://docs.avaloniaui.net/docs/deployment/native-aot), [Native platform interop](https://docs.avaloniaui.net/docs/app-development/native-interop), [macOS](https://docs.avaloniaui.net/docs/platform-specific-guides/macos) |
| Uno Platform | On Android, Uno Platform 7 draws with Skia. The earlier target, where `UIElement` inherited `ViewGroup` and Android ran layout, was removed in 7.0. A native `Android.Views.View` can still be embedded as the content of a `ContentControl`. | [How Uno works on Android](https://platform.uno/docs/articles/uno-development/uno-internals-android.html), [Embedding native elements](https://platform.uno/docs/articles/features/using-skia-hosting-native-controls.html) |
| React Native | The Fabric renderer is a C++ renderer shared across platforms. JavaScript and the host pass values through JSI. The legacy path serialized JSON across an asynchronous bridge. Host components are lazily initialized. | [Fabric](https://reactnative.dev/architecture/fabric-renderer), [New Architecture](https://reactnative.dev/blog/2024/10/23/the-new-architecture-is-here) |
| NativeScript | NativeScript is a JavaScript runtime. Metadata for the public native APIs is generated at build time and bound at runtime, so JavaScript can call those APIs without a separate native module for each call. | [How the bindings work](https://github.com/NativeScript/NativeScript/wiki/Deep-dive:-How-NativeScript%27s-JS--native-bindings-work) |

Nothing in this table was timed against the others on this boot. This tree does not claim the same set of controls, the same hot reload, or the same platforms.

## Hot reload

The rows below are what each project's own page says, and what this tree measured. None of the other products was built or timed on this boot.

| | What a save can change in the running process | Where that is written |
| --- | --- | --- |
| This tree | A screen file in the subset is lowered to an NPC1 record and applied on the NativeAOT listener. `IsDynamicCodeSupported` stays false. A public static method in another file of the same `samples/<name>` folder, when it returns an `Element`, is inlined, and saving it reloads every `*Screen.cs` in that folder. On pid 6912 both screens moved from `banner-v1` to `banner-v2`. A public method marked `[ReloadCallable]`, or a public method in a namespace named by `[assembly: ReloadCallable("Namespace")]`, is a compiled switch (`ReloadDispatch.Call`, opcode `VmApp`). The same pid called `CounterService.Next` (Count 0 became 5) and `LibraryFormat.Label` (`"  Ada  "` became `Ada`). Saving that method's body prints that the body was not swapped. The next launch, pid 7154, ran `return "rebuilt"` and the title became `rebuilt`. A method the table does not list is refused. The listener `.so` and the Release `.so` sizes are in the evidence file. One `RequestRender` on the counter, ten samples, Hyndman-Fan type 7 p50: listener save 519.5 µs before the cut and 56.0 µs after; Release bookkeeping 71.0 µs before and 0 µs after. Release `after` moved from 24.5 µs to 90.0 µs. | [architecture.md](architecture.md), [devx/evidence/render-phases.txt](devx/evidence/render-phases.txt), [devx/evidence/call-table.txt](devx/evidence/call-table.txt) |
| .NET MAUI | The .NET 10 page describes XAML Hot Reload. The app is running in a debug configuration named `Debug`, with the debugger attached. Edits to XAML are parsed and sent to the running app. UI state is preserved when the full page is not recreated. A full page reload can drop focus and selection. The page states that XAML Hot Reload does not reload C# code. Adding, removing, or renaming a file or a NuGet package requires a rebuild and redeploy. The same URL has a separate .NET MAUI 11 preview section for an incremental engine. That section is preview, and it is not the .NET 10 contract. | [XAML Hot Reload for .NET MAUI](https://learn.microsoft.com/en-us/dotnet/maui/xaml/hot-reload?view=net-maui-10.0) |
| Uno Platform | The Hot Reload overview says the feature modifies XAML and C# of the running application. It lists Visual Studio, VS Code, and Rider, and names iOS, Android, WebAssembly, and Skia. Modifying a `UserControl` that is instantiated in more than one place reloads that control and leaves its parents in place. When the solution contains iOS, Android, or WebAssembly heads, the page requires .NET 10 or later. Adding new C# or XAML files is listed as not yet supported on several targets. | [Hot Reload](https://platform.uno/docs/articles/studio/Hot%20Reload/hot-reload-overview.html) |
| Avalonia | The `AvaloniaUI.DiagnosticsSupport.HotReload` package plugs into .NET Hot Reload. The page requires Avalonia 12 or newer and a license key. `dotnet watch` is the documented driver. On mobile, that driver requires .NET 11 or newer. Controls, styles, resource dictionaries, and data templates update. `{StaticResource}` is rewritten to `{DynamicResource}` during hot reload. C# follows the usual .NET Hot Reload rules: adding a field or changing a signature needs a restart. A file watcher can reload `.axaml` without .NET Hot Reload, and the page says that watcher does not reload `.cs`. WebAssembly is not supported. Controls are rebuilt, so state that is not in XAML resets. | [Hot reload](https://docs.avaloniaui.net/tools/hot-reload/) |
| React Native | Fast Refresh is enabled by default. A module that only exports React components is updated and re-rendered. A module that also exports something else is re-run, and so are the modules that import it. A file imported from outside the React tree falls back to a full reload. `useState` and `useRef` keep their values when the hook order and arguments stay the same. Class components reset their state. `// @refresh reset` remounts the components in that file. Hooks that take dependencies, including `useEffect`, `useMemo`, and `useCallback`, run again during refresh. | [Fast Refresh](https://reactnative.dev/docs/fast-refresh) |
